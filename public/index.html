Welcome

This tool sets up per-directory GitHub identity and credential switching — so git push automatically uses the right account based on where your repo lives.

First, generate a GitHub Personal Access Token:

  1. Open github.com/settings/tokens and click Generate new token (fine-grained)
  2. Set a name (e.g. local-dev-mac), expiration, and choose Resource owner (your user or org)
  3. Under Repository access, choose All repositories or select specific ones
  4. Under Permissions, grant:
    • Contents — Read & Write
    • Metadata — Read-only (auto-selected)
    • Workflows — Read & Write
  5. Click Generate and copy the token — it won't be shown again
  6. If your org uses SAML SSO: fine-grained tokens are authorized per resource owner — select the org as resource owner in step 2
  1. Open github.com/settings/tokens and click Generate new token (classic)
  2. Set a note (e.g. local-dev-mac) and choose an expiration
  3. Select scopes: repo, read:org, workflow
  4. Click Generate and copy the token — it won't be shown again
  5. If your org uses SAML SSO: click Configure SSO next to the token and authorize your org
